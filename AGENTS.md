# Правила проекта Dostoevsky

## Утверждённый интерфейс диалогов

Все новые диалоги, реплики, отчёты, записки и другие окна чтения должны использовать текущий общий интерфейс `UDocumentWindow`. Пользователь утвердил этот дизайн 15.11.2026. Сохраняйте его при дальнейшей разработке; изменение оформления требует отдельного запроса пользователя.

- Светло-жёлтая панель `#FFE79D`, чёрный текст, оранжевая пунктирная рамка `#FFB900`, скруглённые углы.
- SOUTHGHETTO для имени персонажа / названия объекта; Cascadia Code Light для основного текста.
- Положение внизу слева и пропорции из `Source/Dostoevsky/Private/DocumentWindow.cpp`. Спецификация: `Docs/DialogueStyle.md`.
- Добавляйте содержимое через `UInteractionDocument` и `NarrativeInteractionComponent` / `NarrativeSubsystem`. Не создавайте отдельные альтернативные окна на Canvas DrawText/DrawRect или независимые Widget Blueprint с другим оформлением.
- Существующие `BP_ApartmentHUD` и `BP_PrologueHUD` используют `BeginStyledDialogue` / `AppendStyledDialogue`; сохраняйте их игровую логику, подсказки и управление.

## Работа с проектом

Основной проект — `Dostoevsky.uproject`, Unreal Engine 5.8 (проверено на 5.8.4). Сначала соберите C++-модуль, затем открывайте Blueprint, которые на него ссылаются. Инструкции для команды — в README.md.

Не коммитьте Binaries, Intermediate, Saved, DerivedDataCache, IDE-кэш и генерируемые solution-файлы. Не переписывайте историю общего репозитория. Согласовывайте одновременное редактирование бинарных карт и Blueprint.

Для изменений C++ используйте проверку сборки. При изменении рамки окна запускайте `Scripts/CheckDialoguePaint.py` через Unreal Python: проверка вызывает настоящий OnPaint на пяти размерах панели без GPU. Не добавляйте в TArray элемент, ссылающийся на тот же массив; копируйте начальную точку контура перед Add.

## HUD свободного перемещения

После вставания Димы показывайте управление сверху слева (W/A/S/D, Space, Shift). Скрывайте весь блок после использования всех шести действий; не засчитывайте ввод за столом или в открытом журнале. Справа сверху сохраняйте значок блокнота и J — журнал. Подключение и проверки описаны в Docs/ExplorationHUD.md. При изменении счётчика кнопок или значка выполняйте Scripts/CheckExplorationHUD.py через Unreal Python.

## Журнал с мышью

В журнале используйте курсор, подсветку строк и левый клик. Не возвращайте выбор документов цифрами 1–4 или цифровым блоком. Показывайте только найденные записи из JournalCatalog; чтение — через общий DocumentWindow. Убирайте дублирующую текстовую легенду управления вне HUD, сохраняя предметные подсказки по E. Инструкция и проверки: Docs/JournalUI.md, Scripts/CheckJournalUI.py.
