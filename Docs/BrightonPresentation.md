# Обновление Брайтон-Бич, версия 0.12.0

На вывеске, в подписях переходов и задачах улица называется **4th Brighton beach**. Техническое имя карты `L_NeptuneStreet` сохранено, чтобы существующие ссылки и переходы продолжали работать.

## Что находится в проекте

- В магазине расставлены 155 предметов: товары на полках и шоколад возле кассы. Использованы исходные `green_can_obj`, `soda_bottle_obj`, `chocolate_bar_obj`, `cash_register_obj` из папки пользователя. Добавлены упаковки молока, хлопьев, крупы, муки, хлеб и яйца. Новый кассовый аппарат стоит на прежнем прилавке; интерактивная покупка сигарет сохранена.
- За пределами доступной территории продолжаются три дороги и 42 фоновых дома. Четыре прежних ограничителя игрока сохранены; дальние декорации не имеют коллизий.
- Фасады получили штукатурку, окрашенную обшивку и несколько вариантов кирпича. Окна выровнены по этажам и шагу фасада. У освещённых окон первого этажа есть прожектор с маской рамы. Дальность света ограничена 26 м; ночью включаются ближайшие источники.
- Вид из квартиры собирается из той же уличной геометрии со смещением вниз на 640 см: игрок видит двор и улицу с третьего этажа. Мебель и игровые координаты квартиры сохранены. Шторы раздвинуты, чтобы не перекрывать проёмы.
- В начале снова играет `S_DimaApartmentAmbient`. Шаги используют четыре набора по четыре варианта: дерево, плитка, сухой асфальт и мокрое покрытие. Звук зависит от фактического перемещения и поверхности под ногами; при остановке и в диалогах шаги не воспроизводятся.
- Дождь использует 480 инстансов капель и 72 кольца брызг. Высота попаданий учитывает землю и навесы. Параметр `Wetness` постепенно затемняет покрытие, уменьшает шероховатость и проявляет лужи. При переходе между картами во время сюжетного дождя улица сохраняет мокрый вид.
- Панель задач и выносливость оформлены как светлые бумажные карточки. Основная задача отмечена ромбом, побочные — точками. Полоса выносливости состоит из коричневых и светлых диагональных полос; истраченная часть чёрная. Временный шрифт **Podkova** согласован пользователем; его лицензия OFL включена рядом со шрифтом. Утверждённое окно диалогов `UDocumentWindow` и управление журналом сохранены.

## Где искать ассеты и код

| Назначение | Папка / файл |
|---|---|
| Импортированные модели продуктов и кассы | `Content/Prologue/Furniture/Grocery` |

| Шаги и таблица окружения | `Content/Prologue/Brighton/Audio`, `DA_Environment` |

| Шаги, намокание, включение света окон | `Source/Dostoevsky/Private/BrightonEnvironment.cpp` |
| Дождь и брызги | `Source/Dostoevsky/Private/ActOneScene.cpp` |
| Бумажные карточки и полоса выносливости | `Source/Dostoevsky/Private/ExplorationHUD.cpp` |

Готовые `.uasset` уже подключены к картам. Для обычного запуска повторный импорт не требуется.

Готовая Windows-сборка находится в `Builds/0.12.0/Windows/Dostoevsky.exe`. Повторная упаковка выполняется из корня проекта:

```powershell
powershell -File Scripts/PackageGame.ps1 -EngineRoot "D:\Epic Games\UE_5.8"
```

Номер каталога сборки берётся из `ProjectVersion` в `Config/DefaultGame.ini`.

## Как повторить изменения

1. Закройте редактор и соберите C++ через `Scripts/BuildEditor.ps1`, указав путь к UE 5.8.
2. Откройте проект и выполните `Scripts/ApplyBrightonUpgrade.py` через меню **Инструменты → Выполнить сценарий Python**. Скрипт сначала копирует затрагиваемые карты в `Saved/Backups/BrightonApply_*`, затем обновляет только свои группы объектов и необходимые ссылки.
3. Для фотографий переходов выполните `Scripts/BakeBrightonViews.py` в редакторе с GPU. Временный дневной свет и камеры используются для снимков и не сохраняются в карту.

`Tools/BrightonResources.py` нужен только для повторной подготовки исходных OBJ, этикеток, звуков и шрифтов. Он запускается обычным Python с `fonttools`, `shapely` и `Pillow`; готовые исходники уже находятся в репозитории.

## Проверки

`Scripts/CheckBrightonAssets.py` запускается через Unreal Python commandlet. Он проверяет модели, материалы, товары, фоновые дома, ограничители, световые маски, смещение вида с третьего этажа и существующие проверки сценария, диалогов, журнала и карт.

`Scripts/CheckBrightonPresentationPIE.py` запускается через `UnrealEditor.exe -ExecutePythonScript=...`. Он проверяет настоящее перемещение и шаги по четырём поверхностям, обучение, журнал с мышью, HUD, дождь, покупку сигарет и переходы между картами. Кадры сохраняются в `Saved/Reviews/Brighton012`.

`Scripts/CheckActOnePIE.py` отдельно проходит три маршрута первого акта: QTE/взлом, пистолет/ключ и тревога после срыва ленты.
