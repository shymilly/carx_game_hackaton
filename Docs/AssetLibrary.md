# Библиотека ассетов с рабочего стола

В Unreal Content Browser откройте **Content → ImportedAssets**.

- **Office** — офисная мебель и предметы, разложенные по исходным категориям.
- **Industrial** — индустриальные здания и детали окружения из FBX/GLB.
- **Nature/Trees** — деревья.
- **Posters** — американские постеры, плоские модели и готовые материалы в `AppliedMaterials`.
- **RetroUrban** — набор PBR-текстур городских поверхностей.
- **TinyTextures/Size128, Size256, Size512** — текстуры соответствующих размеров.
- **FirstPersonArms** — скелетные модели рук, Skeleton и текстуры; старая версия хранится отдельно.

Модели можно перетаскивать из Content Browser на уровень: исходные материалы уже назначены. Из самостоятельных текстур можно создать материал через контекстное меню **Create Material**; для PBR-наборов подключайте карты BaseColor, Normal, Roughness, Metallic и Ambient Occlusion к соответствующим входам материала.

Папка `Desktop/assets` перенесена целиком в `SourceAssets/DesktopAssets` внутри проекта. Сохранены все 1161 исходный файл (402 516 114 байт), в том числе лицензии, Blender-файлы и альтернативные GLB. У одинаковых моделей с парой FBX/GLB импортирована одна геометрия; исходные GLB использованы для восстановления материалов. У индустриального GLB и `trees.glb` нет одноимённых FBX, поэтому они импортированы отдельно.

Unreal работает с подготовленными `.uasset` в Content. `SourceAssets/DesktopAssets` хранит оригиналы с лицензиями для повторного импорта. Эта библиотека, подготовленные файлы `SourceAssets/AssetLibraryProcessed` и готовые ресурсы `Content/ImportedAssets` включены в Git и приходят вместе с проектом. Остальные папки внутри `SourceAssets` по умолчанию игнорируются.

У `OFFICE/textures/office_chair2.jpg` в исходном пакете неверное расширение: внутри PNG. Для импорта подготовлена побайтовая копия с расширением `.png` в `SourceAssets/AssetLibraryProcessed`; оригинал сохранён.

Повторяемый импорт: `Scripts/ImportDesktopAssets.py` через Unreal Python. Скрипт использует манифест, пропускает уже импортированные источники и не меняет игровые уровни. `RepairAssetMaterials.py` восстанавливает исходные материалы без дублирования геометрии. Итоговая проверка и числа ресурсов — `Resources/AssetLibrary/Summary.json`.
